Practical questions

Before you book

Can the car drop us at Ram Mandir entrance?

Usually not. Security and traffic controls mean the final approach commonly involves walking or approved local transport. In reality, the final vehicle stopping point changes with crowd control, security and the date of visit, so guests should expect part of the approach to be on foot or by approved local transport. We plan the drop, guide meeting point and return pickup before the visit so you are not left trying to find the vehicle in a restricted zone.

How long does Ram Mandir darshan take?

There is no dependable fixed duration. Waiting time varies with the date, crowd level and security arrangements. On ordinary days the process can move quite smoothly, but weekends, festival periods and security changes can make the same visit take much longer. We therefore keep the surrounding programme flexible and avoid scheduling a tight onward departure immediately after darshan. The local team reconfirms current access and guides the guest to the practical entry point, but the final waiting time remains with temple and security authorities.

Can this day be slowed down for senior travellers?

Yes. We can reduce optional stops, build in more rest and use local transport where permitted. In practice, the amount of walking depends heavily on that day’s security cordons and where vehicles are stopped, so we never promise a fixed door-to-door drop. If you tell us about knee, back or mobility concerns in advance, we can reduce optional stops, allow more rest time and use approved local transport wherever it is actually permitted.

Is Sarayu Aarti timing fixed all year?

No. The practical reporting time changes with the season and local arrangements, so we reconfirm it before the visit. The ceremony follows local and seasonal arrangements, so the useful information for a traveller is the reporting time rather than an old fixed clock time copied from the internet. We reconfirm it locally and plan the preceding sightseeing so you reach Ram Ki Paidi without rushing.
