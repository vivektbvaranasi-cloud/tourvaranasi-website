# Tour Varanasi — Final Consistent Itinerary Build

This is the corrected production build for Netlify.

## Important itinerary rule now applied
Every tour of more than one day uses one consistent day-by-day layout:
- compact destination/experience photograph on the left
- DAY number, route/day title and detailed narrative on the right
- an explicit Sightseeing line naming the main places
- Overnight line where applicable
- no alternating image/text layout
- on mobile, photograph stacks above the text

This format is applied to all 13 multi-day tour pages (2 to 7 days).
